# _Cuora trifasciata_ genome assembly and annotation 

__Disclaimer__: All scripts in this folder were specifically used for this genome assembly, so to use them for your own data, you will need to change paths and conda environments. 

Ensure the repeat_pipeline.sh, get_chrom_lengths.py, and Cuora_genome.sh scripts are in the same folder. 

### Conda environments: 
* samtools
* hifiasm
* purge_dups
* bwa-mem2
* yahs
* picard
* compleasm
* minimap2
* blastn2dotplots
* liftoff
* orthofinder
* ucsc-kent
* helixer
* tiberius
* Mikado
* kraken2
