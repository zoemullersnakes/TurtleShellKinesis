# Convergence analyses

1) `twisst` - Scripts used for topology weighting analysis with TWISST
2) `selection` - Scripts used for HyPhy selection tests
3) `rerconverge` - RERconverge and phangorn Rscript
4) `genefam` - Scripts used for CAFE5 analysis
5) `cnes` - sbatch scripts used for cactus, PHAST, and PhyloAcc

Disclaimer: We did not modify scripts for external use, so you will need to edit the scripts for your own data!
